# Squad

Мультимодельные системы BB одной командой: совет, арена и команда агентов —
на субтредах BB, с любыми провайдерами, без привязки к Anthropic.

## Что даёт

- `bb squad council <задача>` — совет пяти агентов: параллельный анализ вопроса,
  сравнение ответов, визуальный отчёт.
- `bb squad arena <бриф>` — арена: агенты соревнуются созданием прототипов,
  результаты собираются в галерею.
- `bb squad team <фича>` — команда агентов с ролями (исследователи, архитекторы,
  кодеры, ревьюер, верификаторы): реализация фичи под ключ.

Каждая команда создаёт видимый тред-оркестратор; участники запускаются его
субтредами — всё дерево видно в BB, в каждого участника можно заглянуть.

## Как работает

- Оркестратор получает инструкцию выполнить скилл `bb-council` / `bb-arena` /
  `bb-team` из `skills/` этого плагина (plugin skills tier — доступны всем
  провайдерам BB).
- Флаги `--provider`, `--model`, `--reasoning` задают движок оркестратора;
  по умолчанию — дефолт проекта.
- Ничего не покидает машину: участники — это треды BB на уже настроенных
  провайдерах.
