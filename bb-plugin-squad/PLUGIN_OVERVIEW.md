Мультимодельные системы BB одной командой: совет, арена и команда агентов
на субтредах, с любыми провайдерами.

## What you get

- `bb squad council <задача>` — совет пяти агентов (анализ, отчёт со сравнением).
- `bb squad arena <бриф>` — арена прототипов с общей галереей.
- `bb squad team <фича>` — команда с ролями: реализация фичи под ключ.

## How it works

Команда спавнит видимый тред-оркестратор с инструкцией выполнить скилл
`bb-council` / `bb-arena` / `bb-team` (живут в `skills/` плагина и доступны
каждому провайдеру BB). Оркестратор порождает участников субтредами через
`bb thread spawn --parent-self`; общение — `bb thread tell`. Флаги
`--provider/--model/--reasoning` выбирают движок оркестратора.

## For agents

Используй `bb squad <council|arena|team> "<задача>"`, когда пользователь просит
запустить совет, арену или команду агентов. Команда возвращает id
треда-оркестратора — дальше пользователь наблюдает дерево тредов в BB.
